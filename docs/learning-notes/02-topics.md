# 主题如何生成？

## 关键选择

- 在本地运行 SPECTER2 base 和 proximity adapter。有可用摘要的论文输入题名和摘要，其余输入题名。取 768 维的 [CLS] 向量并做 L2 归一化。模型的预训练利用引文关系，输入来自本项目的书目信息和摘要。[模型说明](https://huggingface.co/allenai/specter2)
- 对四个候选子主题数各使用五个随机种子，以种子两两之间的平均 ARI 选择子主题数。对 k-means 质心做 Ward 层次聚类得到十组宏观主题。UMAP 把已聚类的论文投影到网页使用的二维坐标。[UMAP 文档](https://umap-learn.readthedocs.io/en/latest/clustering.html)
- 逐簇抽取最接近中心、随机及最接近分类边界的论文，结合题名、摘要和主题词审读。主题名是对这些模型分组的编辑性概括。异质性较高的分组会在说明中指出。

## 可复跑命令

```bash
cd pipeline
.venv/bin/python -m pip install -r requirements.lock.txt
.venv/bin/python -m pa_map embed
.venv/bin/python -m pa_map embed --title-only
.venv/bin/python -m pa_map cluster
```

嵌入阶段保留逐篇输入和模型版本的校验值。重复运行时会复用匹配的本地向量，聚类会核验两份向量与当前语料是否一致。若设置了独立的试点数据目录，可用 `PA_MAP_REUSE_EMBEDDINGS` 指向试点的 `private/` 目录。

## 试点结果

- 2016–2025 年起始试点有 3,575 篇合格论文，其中 3,442 篇有可用摘要。30 子主题的平均 ARI 为 0.4460，其次是 40 子主题的 0.4093。在所比较的四个候选值中选取 30。
- 保持聚类中心固定，把所有输入改为只有题名，宏观主题一致率为 73.31%，子主题一致率为 66.21%。原本有可用摘要的记录中，两项一致率为 72.28% 和 64.90%。
- 一组 26 条试点记录集中于封面、订阅说明、编辑文章、书评和奖项通知。这个分组暴露了索引的文献类型误标，并为正式语料清洗提供了可逐条核对的记录。[ASPA 卷期书评目录](https://www.aspanet.org/ASPA/ASPA/Make-Connections/Bridge/102517.aspx) · [Wiley 编辑文章示例](https://onlinelibrary.wiley.com/doi/abs/10.1111/puar.13319)

## 正式语料

- 最终版使用 10,606 篇论文，其中 8,874 篇有可用摘要。候选子主题数为 30、40、50 和 60，各方案的平均 ARI 分别为 0.5538、0.5013、0.4534 和 0.4354。采用 30 个子主题，并合并为十个宏观主题。
- 仅题名输入的宏观主题一致率为 71.42%，子主题一致率为 65.50%。原本有可用摘要的记录中，两项一致率为 65.84% 和 58.77%。
- 审读覆盖每个子主题的中心、随机和边界样本。其中 “Mixed Topics and Sparse Abstracts” 的 678 篇记录只有 170 篇有可用摘要，题名较短且内容跨度较大。该分组保留在地图上，供读者观察覆盖差异。
- 不同随机种子和语料冻结版本下的归类仍会变化。每次重新运行聚类后会生成新标签模板，需要重新核对编号和主题归属。

## 如何解释敏感性检查

- 第一项检查将仅题名向量分配到正式模型的固定 k-means 中心，以同一组主题比较归属和趋势。第二项检查保留正式模型的主题归属，只以有可用摘要的论文为分母。两项的目的分别是观察文本输入变化和样本覆盖变化。

本地 `data/review/` 中的 `topic_review.csv` 支持检查论文样本，`stability.csv` 保存候选方案的 ARI，`sensitivity_cohorts.csv` 给出每刊每年的两组敏感性计数。
