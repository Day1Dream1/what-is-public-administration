# 哪些论文进来了？

日期：2026-11-19

## 关键选择

- 以 OpenAlex 五刊来源记录建立候选池，使用 Crossref 交叉核实卷期、日期和页码。用出版商卷期校准 JPART 线上先发日期。
- 首版纳入 PAR 的实质性实证、理论和综述论文。能确认是编辑文、采访、讲座或约稿观点栏目的记录作排除处理。通用规则会漏掉无明显题名标记的文献类型，逐条证据见[核验报告](../literature-and-journal-audit.md)。
- PAR 的早期 JSTOR 元数据中出现大量重复首页值，不能据此判定只有一页。用明确页码范围判断长度，缺可靠尾页的记录标为页数未知。

## 复跑

```bash
python -m pa_map fetch
python -m pa_map clean
```

## 实际结果

- 抓取 15,559 条 OpenAlex 原始记录及 15,629 个 Crossref 唯一 DOI，含边界年份。按正式卷期及年份处理后，研究窗口内有 14,612 条候选，保留 10,606 条，排除 4,006 条。
- 合格记录中 8,874 条有至少 30 词的可用摘要，1,732 条用题名上图。205 条缺可确定的正式卷期年份，使用来源日期并另计。
- 75 条出版商抽查逐条留证，其中 32 条确认保留、40 条确认排除、3 条未裁定。样本有意覆盖边界情况，不能用于估计全语料误差率。
