## 公共行政站的五章

1. 先读全量地图，再对照共同刊期内两个五年组，揭示三个主题的相反变化，并核对摘要替代口径。
2. 从题名里的 New Public Management 出发，逐项加入 Public Service Motivation 和 Representative Bureaucracy 的词语证据。
3. 在保持投影不变的地图上切换期刊，再读期刊内的主题份额。
4. 依次查看题名中明确出现的案例研究、实验、综述与特定因果设计措辞，给出五年组分母。
5. 从两类方法线索在地图上的位置转入按主题统计的联合分布，讨论这些共现给出的证据边界。

新版共 30 步，沿用一个会随滚动更新的图台。理论和方法图使用可复核的题名短语，某一术语没有出现在题名时，文章仍可能使用相应理论或方法。语义主题和题名短语有共同的文本输入。文案据此将联合分布表述为描述性证据。
