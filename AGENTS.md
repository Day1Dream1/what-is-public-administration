# What Is Public Administration?

Open [the shared project handoff](docs/HANDOFF.md) for the architecture, current release, review steps and GitHub Pages walkthrough.

- Use this repository as the working directory. The parent Obsidian vault contains separate projects.
- UI and prose edits build with the existing public data. `site/public/data/` is generated by the release pipeline. Record eligibility and theme changes in the pipeline inputs and regenerate the release when appropriate.
- Keep `pipeline/data/`, abstracts, embeddings and credentials in the local analysis environment. Use the public, generated data when editing the site.
- Review the Git diff and check the release before publishing a change. For concurrent editing, use separate branches and worktrees.
